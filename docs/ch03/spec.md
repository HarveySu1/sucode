# sucode · Phase 3 规格 —— Agent 编排器与执行策略

> 状态：已与需求方澄清定稿（2026-10-20）；2026-10-21 修订新增 C51/C52（权限确认交互 + 项目记忆提取）
> 本文档只回答「做什么、不做什么、什么算完成」。实现细节见同目录 tasks.md，验收值见同目录 checklist.md。

## 1. 背景

Phase 2 落地了 Agent 循环，但它长在会话对象里、以异步生成器直接喂给唯一消费者（TUI），工具一律串行执行，也没有「模式」概念。Phase 3 把循环升格为独立的**编排器**：过程事件经通道广播（支持多消费者，为后续 headless CLI 铺路）、同轮工具按并发安全性分批执行（读类并发、写类互斥）、新增只规划不执行的**计划模式**、外部**取消信号**可传播到循环、工具执行前后留**拦截位**（权限策略的接入点）、Provider 层支持**最小系统提示词**。

## 2. 能力清单（续 Phase 2 编号）

- C42. Agent 编排器独立：ReAct 循环从会话对象迁出为独立编排器；会话对象退化为历史 + profile + 模式状态的容器（循环、工具执行、事件产出全部归编排器）
- C43. 事件通道：编排器以后台任务运行，全过程事件按序压入通道——用户消息、轮次开始、思考、正文、工具调用开始 / 参数、增量输出、心跳、完成、通知、错误、终止；上层按需消费；**终止事件是唯一结束信号**，后台任务内一切异常（含 Provider 错误）转错误事件收尾，不跨任务抛异常
- C44. 工具分批执行：同轮工具调用序列按并发安全性切批——**相邻的安全调用合并为一批并发执行**（受并发上限约束），不安全调用各自成批串行执行，批与批按原顺序执行；每批等全部完成后统一配对入史
- C45. 并发安全性判定：工具自带**按调用入参动态判定**的方法（非纯分类标签）；基类默认不安全，纯读工具恒安全，命令类工具按只读白名单判定；注册中心查不到的未知工具视为不安全
- C46. 只读白名单共享：命令类工具的只读命令白名单同时服务两个用途——并发安全判定与计划模式拦截；白名单外默认不安全且计划模式下拦截
- C47. plan-only 模式：会话级开关切换；进入后装配计划模式系统提示（约束模型只探索不修改、唯一可写目标为计划文件、四步工作流：探索 → 分析 → 写计划 → 等确认）；写类与非白名单命令类调用被前置拦截并回传结构化提示让模型改道；计划产出写入计划文件；收尾以通知提示用户手动切换执行模式，**不做审批 UI**。退出计划模式后的**首次用户请求**前拼接一次模式切换上下文提示（UI 命令不进历史，模型无从感知切换；提示随该轮用户消息入史，一次生效后自动消失）
- C48. 取消信号传播：外部取消信号（UI 为首个触发源）传递到编排器，**轮次边界检查点**检测到信号后干净退出；即时中断路径（任务取消异常穿透）保留；两条路径共用同一套中断收尾与配对不变量规则（延续 ch02）
- C49. 拦截位：工具执行前后留通用钩子——**前置钩子可否决**（返回结构化结果替代执行），后置钩子只观察；默认无钩子直通；计划模式拦截即第一个内置前置钩子
- C50. 最小 system prompt：Provider 层支持会话级系统提示词传参，双协议各自组装；系统提示词**不进对话历史**；普通模式一条静态最小文案、计划模式专用文案；不做复杂组装
- C51. 风险操作权限确认（2026-10-21 修订新增）：普通模式下写类与非白名单命令类工具执行前，经事件通道发出**权限请求事件**（工具名 + 参数摘要 + 应答 Future）；应答三值——允许（照常执行）/ 拒绝（结构化错误回传模型，工具不执行）/ 本会话内该工具不再询问；读类与只读白名单命令不确认；计划模式保持自动拦截不走确认；等待应答有超时，超时按拒绝
- C52. 项目记忆提取（2026-10-21 修订新增）：每固定次数的编排运行（全部终止原因均计数）后，以后台任务对**会话历史快照**做一次 LLM 总结提取（项目规则 / 工程约定 / 技术约束 / 用户偏好），追加写入工作目录的项目记忆文件；fire-and-forget——不阻塞主流程、失败静默；提取结果不注入系统提示词

## 3. 非功能要求

- N16. 并发上限：安全批内并发度受信号量约束（具体值见 checklist），防无限并发拖垮系统
- N17. 通道语义：单次运行内事件先进先出、不丢不乱；跨运行不复用通道
- N18. 配对不变量在分批下延续：批内全部完成或被取消后统一配对；未开始的批整批配对中断结果；任何路径零孤儿（延续 ch02 C24/C29）
- N19. 异常事件化：后台任务内 Provider 错误、未预期异常一律转错误事件 + 终止事件；取消异常走中断收尾后发终止事件
- N20. 拦截例外的唯一性：计划文件是计划模式下唯一放行的写目标；只读白名单是唯一放行的命令集；两者之外一律拦截
- N21. 并发下的反馈保持：多工具同时产出增量输出与心跳时以调用 id 区分，界面各自独立更新；耗时统计不因并发失真
- N22. 系统提示词零历史污染：带与不带系统提示词的对话历史条目数一致；profile 热切换 / 清空上下文不受影响
- N23. 权限请求的应答经 Future 同进程传递：请求在等待期被取消（Esc / 应用退出）时 Future 悬空无害；应答入口对已失效请求（超时已拒 / 已取消）静默忽略

## 4. 设计骨架（在 Phase 2 骨架上新增 Agent 层）

```
┌────────────────────────────────────────────────────┐
│ TUI 层：消费事件通道（队列取用）；权限确认应答（y/n/a）   │
│         Esc → 取消信号+任务取消                        │
├────────────────────────────────────────────────────┤
│ Agent 层（新增）：ReAct 编排器（后台任务）              │
│   事件通道产出 · 分批执行 · 拦截位 · 计划模式拦截        │
│   取消信号轮间检查点 · 终止事件收尾                     │
│   风险操作权限确认 · 周期性项目记忆提取（后台）          │
├────────────────────────────────────────────────────┤
│ 会话层：历史 + profile + 模式状态（循环逻辑已迁出）       │
├───────────────────────┬────────────────────────────┤
│ Provider 层            │ 工具层                       │
│  + 系统提示词传参        │  + 按入参的并发安全判定        │
│  + 通道事件类型          │  + 命令类只读白名单            │
└───────────────────────┴────────────────────────────┘
```

依赖方向：Agent 层依赖会话层与工具层；TUI 只消费事件通道，不再触碰会话内部。

## 5. 已知限制（接受，不预防）

- L6. 白名单判定按命令首 token + 元字符排除，组合管道命令（即使只读）默认不安全且计划模式下被拦截
- L7. 安全批并发执行时多工具的增量输出在通道内交错（按 id 区分），界面滚动可能跳跃
- L8. 取消信号的轮间检查点是温和退出（当前轮跑完才停）；即时停住仍依赖任务取消路径
- L9. 计划模式放行按目标路径精确匹配；白名单命令假定为无副作用，不防御其间接副作用
- L10. 通道支持多消费者接入，但本期实际消费者仅 TUI 一个；事件多播（复制到多队列）不做
- L11. 记忆提取为追加式写入：不去重不合并，记忆文件随使用持续增长（治理留后续章节）；提取质量依赖模型输出，不做校验；always 授权仅会话级（不持久化），重启后重新询问

## 6. Out of Scope（本期明确不做）

- O16. headless CLI 消费入口（如一次性执行命令行提问）——通道能力就绪，入口留后续章节
- O17. 权限规则引擎与持久化授权（细粒度策略、跨会话记忆授权、审批流不做；2026-10-21 修订后本期能力为交互式确认 + 会话级 always）
- O18. 复杂系统提示词组装（环境信息注入、项目上下文、动态拼装）——**记忆提取结果亦不注入**（见 O22）
- O19. 计划审批交互 UI（批准 / 继续计划的选择组件）；仅通知提示 + 手动切换
- O20. 事件多播（fan-out 到多队列）、跨会话通道复用、多会话并行
- O21. 写类工具的依赖感知调度（纯顺序保证，不做依赖图）
- O22. 记忆的注入与治理（提取结果不进系统提示词；不去重、不合并、不检索；文件治理留后续章节）

## 7. 完成定义

Phase 3 完成当且仅当：checklist.md 全部条目实际操作通过，含三条硬性要求：mock 回归全绿（Phase 1 原 12 用例 + Phase 2 原 26 用例不回归破坏）；真实 API 下模型同轮发起**多个读类工具并发执行**且界面可观测；真实 API 下计划模式全流程跑通（写类被拦截、模型改道、计划真实落盘、收尾提示），且 Esc 与取消信号两条中断路径后历史配对不变量保持。2026-10-21 修订追加两条：真实 API 下普通模式写类工具触发权限确认、允许后真实落盘、拒绝后模型收到结构化错误且文件未落盘；连续 5 次运行后工作目录的项目记忆文件真实生成。
